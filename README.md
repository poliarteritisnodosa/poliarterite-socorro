# UMA NOVA CHANCE · PAN

Site estático para GitHub Pages.

## Publicação
1. Envie **index.html** e a pasta **assets/** para a raiz do repositório `poliarterite-socorro`.
2. No GitHub, confirme Settings → Pages → Deploy from a branch → main / (root).
3. Abra https://poliarteritisnodosa.github.io/poliarterite-socorro/ e teste os botões, inclusive no celular.

## Conteúdo
- Fotos fornecidas pelo organizador.
- QR Codes Wise USD e EUR associados a valores fixos; BRL aguardando imagens.
- Meta total não aparece no site.
- Não há backend nem processamento de pagamento: o visitante deve ler o QR Code no app de pagamento.

## Verificação antes da publicação
Confirme individualmente todos os códigos Wise (moeda, valor, beneficiário, validade, leitura) em um dispositivo separado. Alguns códigos podem ser solicitações de pagamento com validade ou limites. Verifique que as fotos das crianças podem ser divulgadas publicamente.
